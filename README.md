# Edupulse-cdd
ABSTRACT

The Student Academic Performance Analyser and Smart Assignment Management System is a web-based application designed to help students monitor their academic performance and manage assignment deadlines efficiently. The system consists of three modules: CIE Performance Analyser, SGPA Calculator, and Smart Assignment Deadline Tracker.

The CIE Performance Analyser calculates internal assessment marks and checks eligibility criteria. The SGPA Calculator computes the Semester Grade Point Average using assessment marks, SEE marks, and course credits. The Smart Assignment Deadline Tracker helps students manage assignments and monitor deadlines through colour-coded status indicators.

The application is developed using Python and Streamlit, with SQLite for database management. A centralized dashboard integrates all three modules, reducing manual calculations, preventing missed deadlines, and improving academic planning and time management.
